ClassWork

Create a simple student profile page, the page should respond to the users actions using event listeners.

    1. your page should contian:
    • A heading that says "Student Profile"
    • an input field for the student name
    • an input field for the student age
    • an dropdown list containing the three favorite subjects
    • a button labeled show message
    • a form with a button labelled "Submit Profile"
    • A paragraph for displaying message
  2. Use the input event

    when the student types their name display the name in a paragraph immediately as they type

  3. use the change event

    when the student selects a different subject from the dropdown display the selected language on the page

  4. use the click event

    when the student clicks the "show message" button display a welcome message for the student

  5. use the mouseover event

    when the student hovers over the heading change its text to "Welcome to my profile"

  6. use the keydown event

    when the student presses a key while typing in the name input, display a message saying "You pressed a key"

  7. use the submit event

    when the student submits the form display a message that says "Profile Submitted" and display the name and age

Prevent the form from refreshing the page when submitted
