JavaScript Notes: Functions, Loops & Conditional Statements

Three core building blocks, explained in simple terms with short examples. They connect to the objects notes, since you use all of these together when working with objects.

PART 1: CONDITIONAL STATEMENTS

Conditionals let your code make decisions: "if this is true, do that; otherwise, do something else."

1.1 if

Runs a block of code only when the condition is true.

let age = 20;
if (age >= 18) {
    console.log("Adult");
}

1.2 if...else

Gives you a second path for when the condition is false.

if (score >= 50) {
    status = 'Pass';
} else {
    status = 'Fail';
}

1.3 if...else if...else

Use when there are more than two outcomes. JavaScript checks from top to bottom and runs the first condition that is true, then skips the rest.

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else {
    grade = 'F';
}

Because it stops at the first match, you don't need to write score >= 80 && score < 90. If the score were 95, the first branch would already have caught it.

1.4 Comparison operators

Operator Meaning Example
=== equal value and type 5 === 5 → true, 5 === "5" → false
!== not equal 5 !== 6 → true
> < greater / less than 10 > 3
>= <= greater or equal / less or equal score >= 50

Tip: Prefer === over ==. The double version converts types behind your back (5 == "5" is true), which causes sneaky bugs.

1.5 Logical operators

Combine several conditions.

Operator Name Meaning
&& AND both sides must be true
|| OR at least one side must be true
! NOT flips true ↔ false 
if (score >= 90 && score <= 100) { ... }   // between 90 and 100
if (day === "Sat" || day === "Sun") { ... } // weekend
if (!isLoggedIn) { ... }                    // NOT logged in

1.6 switch

A tidier option when you compare one value against many exact matches.

switch (day) {
    case "Mon":
        console.log("Start of week");
        break;
    case "Fri":
        console.log("Almost weekend");
        break;
    default:
        console.log("Regular day");
}
  • break stops execution from "falling through" into the next case.
  • default runs when nothing matches (like else).

1.7 Ternary operator (one-line if/else)

let status = score >= 50 ? 'Pass' : 'Fail';
// condition ? valueIfTrue : valueIfFalse

Good for short, simple decisions. For anything longer, use a normal if.

1.8 Truthy and falsy

In a condition, JavaScript treats some values as false. These are the falsy values:

false, 0, "" (empty string), null, undefined, NaN

Everything else is truthy. So if (name) {...} runs only when name has real content.

PART 2: LOOPS

Loops let you repeat code without writing it over and over.

2.1 for loop

Best when you know how many times to repeat.

for (let i = 0; i < 5; i++) {
    console.log(i);   // 0, 1, 2, 3, 4
}

It has three parts inside the brackets:

  1. Start: let i = 0 (runs once at the beginning)
  2. Condition: i < 5 (checked before every round; the loop stops when false)
  3. Update: i++ (runs after every round; adds 1 to i)

Looping through an array by index:

let friends = ['Alice', 'Bob', 'Charlie'];
for (let i = 0; i < friends.length; i++) {
    console.log(friends[i]);
}

2.2 while loop

Best when you don't know how many rounds you'll need. It keeps going while the condition is true.

let count = 0;
while (count < 3) {
    console.log(count);
    count++;          // don't forget this, or the loop never ends!
}

2.3 do...while loop

Like while, but it runs at least once, because the condition is checked after the code block.

let num;
do {
    num = Number(prompt("Enter a number above 0:"));
} while (num <= 0);

Handy for asking the user for input until it's valid.

2.4 for...of loop (arrays)

Gives you each value directly. Cleaner than the classic for when you don't need the index.

for (let friend of friends) {
    console.log(friend);
}

2.5 for...in loop (objects)

Gives you each key of an object.

for (let key in Student) {
    console.log(`${key}: ${Student[key]}`);
}

Memory trick: of → values, in → keys. Avoid for...in on arrays; use for...of or for.

2.6 Array methods that loop for you

Method What it does Returns
forEach runs a function on each item nothing
map transforms each item new array (same length)
filter keeps items that pass a test new array (maybe shorter)
find gets the first item that passes one item (or undefined)
reduce combines all items into one value single value 
let nums = [1, 2, 3, 4];

nums.forEach(n => console.log(n));          // prints each
let doubled = nums.map(n => n * 2);         // [2, 4, 6, 8]
let evens = nums.filter(n => n % 2 === 0);  // [2, 4]
let total = nums.reduce((sum, n) => sum + n, 0); // 10

2.7 break and continue

  • break exits the loop completely.
  • continue skips the current round and moves to the next one.
for (let i = 1; i <= 5; i++) {
    if (i === 2) continue;   // skip 2
    if (i === 4) break;      // stop at 4
    console.log(i);          // 1, 3
}

2.8 Infinite loop warning

If the condition never becomes false, the loop never stops and your browser/tab freezes. Typical causes: forgetting count++ in a while, or a condition that's always true.

PART 3: FUNCTIONS

A function is a reusable block of code with a name. Write once, use many times.

3.1 Function declaration

function greet(name) {
    return `Hello, ${name}!`;
}

greet("George");   // "Hello, George!"
  • name is a parameter: a placeholder for the input.
  • "George" is the argument: the real value you pass in.
  • return sends a value back out and ends the function.

Defining a function does nothing by itself. It only runs when you call it with ().

3.2 Function expression

The function is stored in a variable.

const add = function(a, b) {
    return a + b;
};
add(2, 3);   // 5

3.3 Arrow function

A shorter modern syntax.

const add = (a, b) => a + b;        // one-liner: return is implied
const square = n => n * n;          // one parameter: brackets optional
const greet = (name) => {           // multiple lines: use { } and return
    return `Hello, ${name}`;
};

Heads-up: arrow functions don't have their own this, so avoid them as methods inside objects.

3.4 Parameters: defaults and multiple inputs

function greet(name = "Guest") {   // default value if nothing is passed
    return `Hello, ${name}`;
}
greet();          // "Hello, Guest"
greet("Ada");     // "Hello, Ada"

3.5 return vs console.log

return console.log
Purpose hands a value back to the caller prints to the console for you to see
Can you use the result? yes: let x = add(2, 3) no

A function with no return gives back undefined.

3.6 Scope: where variables live

let globalVar = "I'm everywhere";

function test() {
    let localVar = "I only exist inside test";
    console.log(globalVar);   // works
}

console.log(localVar);  // ERROR: not accessible out here
  • Global scope: declared outside everything, visible everywhere.
  • Local (function) scope: declared inside a function, visible only there.
  • let and const are also block scoped: they only exist inside the nearest { }.

3.7 Functions that call other functions

Break big jobs into small, single-purpose functions. This is exactly how your student exercise was built:

displayStudentInfo();
calculateStudentGrade();
determineStudentStatus();
displayStudentInfoWithNewProperties();

Each function does one job, which makes code easier to read, test and reuse.

3.8 Callback functions

A function passed into another function as an argument.

let friends = Student.friends.filter(function(friend) {
    return friend.length > 3;
});

The function inside filter(...) is a callback: filter calls it on every item. Arrow-function version: friends.filter(f => f.length > 3).

3.9 Functions in objects (methods)

const Student = {
    name: "John",
    greet: function() {
        return `Hi, I'm ${this.name}`;
    }
};
Student.greet();

this refers to the object the method belongs to.

PUTTING IT ALL TOGETHER

One short example using all three ideas:

function gradeAll(scores) {                 // FUNCTION with a parameter
    let results = [];

    for (let score of scores) {             // LOOP over the array
        let grade;

        if (score >= 70) {                  // CONDITIONALS
            grade = 'A';
        } else if (score >= 50) {
            grade = 'B';
        } else {
            grade = 'F';
        }

        results.push({ score, grade });     // build an array of objects
    }

    return results;                         // send the result back
}

console.log(gradeAll([85, 60, 30]));
// [ {score: 85, grade: 'A'}, {score: 60, grade: 'B'}, {score: 30, grade: 'F'} ]
