JavaScript Objects: Study Notes

Based on your code snippet. Each section explains one idea in simple terms, with a short pointer to related topics (loops, functions, conditionals, etc.).

1. What is an object?

An object stores related information together as key: value pairs (called properties). Think of it like a labelled box or an ID card: each label (key) points to a piece of data (value).

let Laptop = {
    name: "Laptop",
    price: 1000,
    quantity: 5
}
  • name, price, quantity are the keys.
  • "Laptop", 1000, 5 are the values.
  • Values can be any type: string, number, boolean, array, function, or even another object.

Why use objects? Instead of loose variables like laptopName, laptopPrice, laptopQty, you keep everything about one "thing" in one place.

2. Three ways to create objects

a) Object literal (most common)

Just write { } with the properties inside.

const Car = { make: 'Chevrolet', model: 'Camaro', year: 2021 };

b) Object constructor

const Bike = new Object({ make: 'Trek', model: 'Domane', year: 2022 });

This works, but the literal { } is shorter and preferred. In your snippet, you pass an object into new Object(...), which just returns that same object, so it behaves exactly like a literal.

c) Factory function

A function that builds and returns a new object each time (see Section 8).

Note: const on an object means the variable can't be re-assigned to a different object, but you can still change the properties inside it.

3. Accessing properties

Two ways:

Style Example When to use
Dot notation Bike.make Normal case, when you know the key name
Bracket notation Car['make'] When the key is in a variable or has spaces/special characters 
console.log(Car['make']);  // Chevrolet
console.log(Bike.make);    // Trek

Bracket notation is what makes looping over keys possible (Section 7), because the key is stored in a variable: Student[key].

4. Adding, changing and deleting properties

Objects are dynamic: you can modify them after creating them.

Student.favoriteFood = "chinese Rice and Ramen"; // ADD a new property
Student.age = 25;                                 // UPDATE an existing one
delete Student.grade;                             // DELETE a property
  • If the key doesn't exist, assigning creates it.
  • If the key exists, assigning overwrites it.
  • delete removes the key and its value completely.

5. Methods and the this keyword

A method is a function stored inside an object.

displayInfo: function() {
    return `Name: ${this.name}, Age: ${this.age}, Score: ${this.Score}`;
}
  • this means "the object this method belongs to". So this.name reads the name of that object.
  • Call it with parentheses: Student.displayInfo().
  • Without the (), you get the function itself, not its result.

You can also attach a method later, as the snippet does with Student.grade = function(Score) {...}.

Related topic: functions. A method is just a function with a home. Everything you know about parameters and return still applies.

Related topic: template literals. The backtick strings `...${value}...` let you drop variables straight into text with ${ }.

6. Nested objects and arrays inside objects

A property's value can itself be an object or an array.

const Student = {
    name: 'John Doe',
    education: { degree: 'Bachelor of Science', major: 'Computer Science' }, // nested object
    friends: ['Alice', 'Bob', 'Charlie'],                                     // array
    sibling: { name: 'Jane Doe', relationship: 'Sister', age: 18 }
}

Chain the access step by step:

Student.education.degree   // 'Bachelor of Science'  (object inside object)
Student.friends[0]         // 'Alice'                (array index starts at 0)
Student.sibling['name']    // 'Jane Doe'             (bracket works too)

Read it left to right: "Student, then education, then degree."

Related topic: arrays. Array positions are called indexes and start at 0. friends.length gives the number of items.

7. Looping with objects and arrays

Looping over an array's items

// for...of: gives you each VALUE directly
for (let friend of Student.friends) {
    console.log(friend);
}

// classic for loop: gives you the INDEX, so you use friends[i]
for (let i = 0; i < Student.friends.length; i++) {
    console.log(Student.friends[i]);
}

Looping over an object's keys: for...in

for (let key in Student) {
    console.log(`${key}: ${Student[key]}`);
}
  • key takes each property name in turn (name, age, Score...).
  • Student[key] uses bracket notation to get the value for that key.

Quick memory trick:

  • for...of → loops over values (arrays)
  • for...in → loops over keys (objects)

Filtering an array

let friends = Student.friends.filter(function(friend) {
    return friend.length > 3;
});

filter goes through an array and returns a new array containing only the items that pass the test (here: names longer than 3 letters). The original array is unchanged.

8. Functions + objects together

Factory function: a function that builds objects

function createStudent(name, age, score) {
    return {
        name: name,
        age: age,
        score: score,
        displayInfo: function() {
            return `Name: ${this.name}, Age: ${this.age}, Score: ${this.score}`;
        }
    }
}

let student1 = createStudent("John", 20, 90);
let student2 = createStudent("Jane", 22, 85);

Instead of writing the same object by hand again and again, you call the function with different arguments and get a fresh object each time. Each one has its own data but the same shape.

Passing an object into a function

function displayStudent(student) {
    console.log(`name: ${student.name}, Age: ${student.age}, Score: ${student.score}`);
}
displayStudent(student1);

The whole object goes in as one parameter, and the function reads its properties with dot notation.

Good to know: objects are passed by reference. If a function changes student.score, the original object changes too (this is exactly how Section 9 works).

9. The student grading exercise, step by step

Getting input from the user

let student = {
    name: prompt("Enter your name: "),
    age: Number(prompt("Enter your age: ")),
    score: Number(prompt("Enter your score: ")),
    course: prompt("Enter your course: "),
};
  • prompt() opens a popup box and returns whatever the user types, always as a string.
  • Number(...) converts that string into a number so you can compare scores properly.
  • The results are stored straight into the object's properties.

Task 1: display the info

function displayStudentInfo(){
    alert(`Student Information:\n Name: ${student.name} ...`);
}

alert() shows a popup message. \n means "new line".

Task 2: calculate the grade (conditionals)

function calculateStudentGrade(){
    let score = student.score;
    if (score >= 90 && score <= 100) {
        student.grade = 'A';
    } else if (score >= 80 && score < 90) {
        student.grade = 'B';
    } // ... C, D, F ...
    else {
        student.grade = 'Invalid score';
    }
}
  • Uses if / else if / else: JavaScript checks from top to bottom and runs the first condition that is true.
  • && means AND: both sides must be true (score >= 90 && score <= 100).
  • The function adds a new property (grade) to the existing object. This ties back to Section 4.

Task 3: pass or fail

function determineStudentStatus(){
    if (student.score >= 50) {
        student.status = 'Pass';
    } else {
        student.status = 'Fail';
    }
}

Same idea with a simple two-way if / else. It adds the status property.

Run order matters

displayStudentInfo();           // shows original 4 properties
calculateStudentGrade();        // adds grade
determineStudentStatus();       // adds status
displayStudentInfoWithNewProperties(); // shows all 6 properties

The functions must run before the final display, otherwise student.grade and student.status would be undefined.

Related topic: function declarations vs calls. Writing function foo() {} only defines it. Nothing happens until you call it with foo().

10. Common gotchas

  1. Case-sensitive keys. Student.Score and Student.score are different properties. In the commented code the key is Score, but in createStudent it's score. Pick one style (lowercase score is the convention) and stick with it.
  2. prompt and alert only work in a browser. They won't run in Node.js. Use console.log there.
  3. prompt returns strings. Always convert with Number() when you need maths or comparisons.
  4. Dot vs bracket. obj.key looks for a property literally named "key". Use obj[key] when key is a variable.
  5. Forgetting () when calling a method. Student.displayInfo is the function; Student.displayInfo() runs it.
  6. Extra spaces in alerts. Putting each line of a template literal on its own indented line adds those spaces into the popup text. Keep lines flush left or join with \n only.
  7. Arrow functions and this. Inside object methods, use regular function() {}. Arrow functions don't have their own this, so this.name won't work.

11. Quick cheat sheet

const obj = { a: 1, b: 2 };      // create
obj.a                            // read (dot)
obj['b']                         // read (bracket)
obj.c = 3;                       // add
obj.a = 10;                      // update
delete obj.b;                    // remove
'a' in obj                       // does key exist? true
Object.keys(obj)                 // ['a', 'c']
Object.values(obj)               // [10, 3]
Object.entries(obj)              // [['a', 10], ['c', 3]]
for (let k in obj) { ... }       // loop over keys
